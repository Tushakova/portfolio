    About the project

    London Data Radar is a small data product built to solve a practical discovery problem: useful analytics events are fragmented across organisers, communities and event websites.

    A Python ingestion pipeline collects events from multiple public sources, normalises them into a common schema, validates the resulting dataset and publishes refreshed data automatically.

    Search and filters cover the events already collected here. Discovery covers selected organisers and public Meetup search listings, including a targeted search for data career events. It does not cover every independent event website; suggest its link to have its organiser considered as a source.
